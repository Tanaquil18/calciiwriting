    🔗

    (a)

    Complete the table below by computing derivatives of \(T_2(x)\) and \(\cos(x)\) and evaluating them at \(x=0\) as directed.
    🔗

    \(f'(x)=\) \(T_2'(x)=\)
    \(f''(x)=\) \(T_2''(x)=\)
    \(f(0)=\) \(T_2(0)=\) \(b_0\)
    \(f'(0)=\) \(T_2'(0)=\)
    \(f''(0)=\) \(T_2''(0)=\)

    (b)

    Now, since we want \(T_2(x)\) and \(\cos(x)\) to have the same height at \(x=0\text{,}\) set \(T_2(0)=f(0)\text{.}\)
    🔗
    This implies \(b_0={}\).

    Since we want \(T_2(x)\) and \(\cos(x)\) to have the same slope at \(x=0\text{,}\) set \(T_2'(0)=f'(0)\text{.}\)
